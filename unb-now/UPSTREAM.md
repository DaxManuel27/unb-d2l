commit `801a1b1a076db357bebeb1f492d270a05c54dac4`.

The upstream MIT license is preserved in LICENSE. Bundled fonts retain their

Eric Zou, WATnow, D2L, or the University of New Brunswick.

UNB changes: branding and host restriction to lms.unb.ca; enrollment discovery
without Waterloo term codes; four-digit course codes; no telemetry; restricted
API transport and messaging; pagination failure handling; account-aware refresh;
local tests and install documentation. Upstream UI, API readers, date grouping,
reminders, and themes are retained.
